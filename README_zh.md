编译生成的合约产物可通过 [unpkg.com](https://unpkg.com/browse/@uniswap/v2-core@latest/) 浏览。

# 本地开发

以下内容假定使用 `node@>=10`。

## 安装依赖

`yarn`

## 编译合约

`yarn compile`

## 运行测试

`yarn test`
